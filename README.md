# DevOps-Copilot-AI-Powered-Build-Failure-Analysis-Platform
AI-powered DevOps assistant that analyzes CI/CD build logs and Python source code to diagnose failures and suggest fixes. Combines a deterministic rule engine (Maven, Gradle, Docker, Jenkins), Python AST-based static analysis, a calibrated ML classifier, and optional local LLM enrichment via Ollama. Built with FastAPI and React.
